# Видео

В форме создания или обновления архива включите «Скачать видео». Для старой записи выберите «По ссылкам». «Продолжить» использует настройки сохранённой задачи и подхватывает незаконченные файлы.

Вставки `lj-embed` разрешаются через страницу соответствующей записи под сессией владельца. В базе остаются адреса роликов, без временных токенов плеера ЖЖ. Распознаются YouTube, VK Video, Vimeo и прямые ссылки на MP4/WebM. Адреса других встроенных материалов сохраняются ссылками.

Для скачивания используется yt-dlp. Выбирается готовый файл со звуком до 720p; если его нет, поддерживаемые отдельные видео- и аудиодорожки объединяются локально. FFmpeg и Deno включены в сборки приложения. Прямые эфиры и плейлисты не скачиваются. Недоступные ролики остаются в очереди с причиной ошибки.

Все сетевые обращения загрузчика, включая метаданные, перенаправления и повторы, проходят через общий счётчик запросов и паузу. Пароль и сессия ЖЖ не передаются видеосервисам. Частично скачанные файлы находятся в `.video-work`, продолжаются при следующем запуске и не входят в ZIP. Готовые файлы — в `media`.

В исходном JSON `videos` содержит исходные адреса, статусы, метаданные, пути, размер и ошибки; `video_embeds` связывает вставки ЖЖ с адресами роликов. ActivityStreams представляет ролики как `Video` с `ja:localPath`, а полный исходный JSON сохраняется без потерь. Текст постов и комментариев не изменяется.

Локальный проигрыватель работает в браузере и при открытии HTML с диска. Приложение поддерживает HTTP Range для перемотки. Наличие картинки или ссылки не считается успешной загрузкой видео.
