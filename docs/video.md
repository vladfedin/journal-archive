# Видео

В форме создания или обновления архива включите «Скачать видео». Для старой записи выберите «По ссылкам». «Продолжить» использует настройки сохранённой задачи и подхватывает незаконченные файлы.

Вставки `lj-embed` разрешаются через страницу соответствующей записи под сессией владельца. В базе остаются адреса роликов, без временных токенов плеера ЖЖ. Распознаются YouTube, видео самого ЖЖ, VK Video, Vimeo и прямые ссылки на MP4/WebM. Адреса других встроенных материалов сохраняются ссылками.

Для скачивания используется yt-dlp. Выбирается готовый файл со звуком до 720p; если его нет, поддерживаемые отдельные видео- и аудиодорожки объединяются локально. FFmpeg и Deno включены в сборки приложения. Прямые эфиры и плейлисты не скачиваются. Недоступные ролики остаются в очереди с причиной ошибки.

Все сетевые обращения загрузчика, включая метаданные, перенаправления и повторы, проходят через общий счётчик запросов и паузу. Пароль и сессия ЖЖ не передаются видеосервисам. Частично скачанные файлы находятся в `.video-work`, продолжаются при следующем запуске и не входят в ZIP. Готовые файлы — в `media`.

В исходном JSON `videos` содержит исходные адреса, статусы, метаданные, пути, размер и ошибки; `video_embeds` связывает вставки ЖЖ с адресами роликов. ActivityStreams представляет ролики как `Video` с `ja:localPath`, а полный исходный JSON сохраняется без потерь. Текст постов и комментариев не изменяется.

Локальный проигрыватель работает в браузере и при открытии HTML с диска. Приложение поддерживает HTTP Range для перемотки. Наличие картинки или ссылки не считается успешной загрузкой видео.

## Загрузка из открытой записи (0.7.6)

Откройте архив через приложение. Кнопка «Загрузить» рядом с отсутствующей картинкой или ссылкой на поддерживаемое видео скачивает только выбранный материал. «Загрузить вставку» получает адрес вставки `lj-embed` со страницы исходного поста. Если для этого требуется вход, пароль вводится локально и не сохраняется.

Файл сразу появляется на странице; затем пересобираются HTML, исходный JSON, ActivityStreams и отчёт. Исходные тексты не меняются. Для следующего просмотра файл остаётся в `media`, в том числе при открытии архива с диска. При ошибке доступен повтор и показана причина. Очередь работает последовательно и ждёт окончания основной выгрузки или переноса архива. Закрытие вкладки не отменяет очередь; выход из приложения отменяет её, незаконченные видео сохраняют возможность продолжения.

Пауза и заданный предел запросов берутся из текущей задачи этого архива. При отсутствии предела одна ручная загрузка ограничена 50 сетевыми запросами, включая перенаправления и повторы; это не ограничивает обычную выгрузку журнала. Сохранённый Retry-After соблюдается и после перезапуска.

Вставки Яндекс Музыки распознаются отдельно: сохраняется канонический адрес виджета, а не аудиофайл. «Онлайн-плеер» обращается к музыкальному сервису только после нажатия. В JSON это external_embeds со статусом online_only; временные адреса и токены оболочки ЖЖ туда не попадают.

## Видео ЖЖ

Поддерживаются вставки `data-rambler-player-id` с числовым ID и `record::UUID`. Приложение получает временное разрешение со страницы поста, проверяет его через `video/check` и запрашивает текущий Rambler Player API. Токен существует только в памяти. HLS-сегменты проходят через тот же счётчик запросов и отмену; FFmpeg собирает локальный MP4 со звуком. Если доступ не подтверждён, ролик остаётся ожидающим входа.

## Галерея и профиль

Раздел «Материалы» показывает изображения, видео и юзерпики. Нажатие на изображение открывает пост или комментарий; «Где встречается» содержит все найденные ссылки. «Файл» открывает сохранённый оригинал. Отсутствующие материалы можно загрузить через приложение. Галерея разбита на страницы и работает с диска; её индекс записывается в `data/materials.json`.

В разделе «Профиль» кнопка «Загрузить профиль» отдельно получает доступные сведения, друзей, подписки, юзерпики и настройки. Пароль вводится локально. Посты, комментарии и очередь основного экспорта не обходятся заново. Ошибки отдельных разделов сохраняются; ранее полученные данные остаются. Полный состав исходных данных доступен в JSON.
