# Архив ЖЖ 0.7.7

Исправления по первым отзывам пользователей:

- Повторные ошибки одного сервера изображений больше не останавливают загрузку картинок со всех остальных. Сбойный источник откладывается до следующего запуска; паузы, `Retry-After` и общий лимит запросов соблюдаются.
- Меню архива сохраняет открытое состояние и клавиатурный фокус при обновлении списка.
- **Параметры** доступны из карточки задачи, меню архива и перед продолжением: объём, изображения, видео, личные данные, пауза и лимит. Старые настройки, которые не были сохранены, не подменяются догадками.
- При продолжении видны подготовка и проверка файлов до входа в ЖЖ. Проверку можно остановить, в том числе во время чтения большого видеофайла.

Постоянный отказ сервера и удалённый файл по-прежнему отмечаются как пропуски. Исправление повторов не гарантирует восстановление недоступных материалов. Существующие архивы и тексты сохраняются.

Сборки публикуются отдельно по мере готовности.
