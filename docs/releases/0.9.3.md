# Архив ЖЖ 0.9.3

- При обновлении журнала за период или по ссылкам хронология показывает всю историю журнала, а не только обновляемые записи. Это касается загрузки на странице «Архивы», карточки журнала и страницы «Хронология». Записи, сохранённые раньше, не отмечаются как ещё не полученные. В строке загрузки видно, сколько всего записей в журнале и сколько из них в этой загрузке.
- В статистике тысячи пишутся сокращённо: 1,1K, 12K, 999K, 1,2M. Точное число видно в подсказке при наведении. Числа до миллионов помещаются в клетки по годам на любой ширине окна. При первом открытии сохранённого архива он коротко подготовится, чтобы получить новое оформление.

Обновление доступно из раздела «Архивы» → «Обновления приложения». Пакеты Windows и macOS распространяются без цифровой подписи издателя.
