# Архив ЖЖ 0.8.9

- Исправлено получение видео ЖЖ, чей старый числовой ID заменён на UUID. Соответствие проверяется через видеосервис; отсутствие прежнего ID больше не вызывает повторный запрос пароля.
- Материалы ЖЖ используют уже открытый сеанс Chrome/Edge. Новый вход предлагается при потере сеанса или получении страницы входа; отсутствие вставки и отказ конкретного видео показываются отдельно.
- В карточке видны этап загрузки, объём файла и итог «Сохранено». Запросы и ответы сервера доступны в «Подробностях». Обновление страницы подхватывает текущую задачу.
- После загрузки одного материала обновляются только записи, где он встречается, галерея и данные архива. При ошибке страницы постов не пересобираются. Полная смена оформления при обновлении версии остаётся отдельной операцией.
- У несохранённых изображений и видео всегда видна исходная ссылка, в том числе в галерее и офлайн-архиве.

Windows: запустите новый EXE. Прежние архивы и прогресс сохраняются. Для браузерного входа нужен Chrome или Edge. Пакеты пока без доверенной подписи Windows и Apple Developer ID/notarization.
