Добавлена иконка вкладки для приложения и всех страниц архива. SVG и ICO включены в приложение и ZIP архива; работают без интернета.

Оформление существующих архивов обновится при открытии в приложении или скачивании ZIP. Вход в ЖЖ для этого не нужен.

Windows x64: запустите EXE. macOS Apple Silicon / Intel: распакуйте соответствующий ZIP и откройте приложение. Linux x64: распакуйте TAR.GZ и запустите `LiveJournalArchive`. Python устанавливать не нужно.

Пакеты без доверенной подписи Windows и Apple Developer ID/notarization. Контрольные суммы `.sha256` приложены.
