# Архив ЖЖ 0.7.9

- Паузы: причина ожидания, источник, номер попытки и обратный отсчёт. Отдельно показываются время работы, время ожидания и последнее сохранение. Статус паузы снимается при отправке следующего запроса; сетевой таймаут больше не обозначается как ограничение сервера.
- Подготовка продолжения показывает проверку записей и файлов. Её можно остановить до сетевых запросов.
- Диагностика: просмотр и сохранение JSON из карточки загрузки или меню архива. Отчёт содержит версию, параметры, последние сетевые события и причины пропусков по отдельным материалам. Тексты, имена, адреса материалов и реквизиты входа исключены.
- Статистика обновляется во время выгрузки. Пересчёт идёт в фоне, по согласованному снимку базы; дата снимка видна на странице. Выбранные фильтры сохраняются. Списки обсуждений также обновляются.
- Календарь: переход по году из ленты, месяцы, недели и дни, плотность публикаций цветом, выбор периода. Масштабы по времени и по числу записей помогают увидеть паузы и серии публикаций.
- Автор журнала включён в статистику по умолчанию; его можно скрыть флажком.

Повторы сохраняют прежние интервалы, общий лимит и срок ожидания, указанный сервером. Диагностика помогает определить причину недоступности файла; она не восстанавливает удалённые материалы или запрещённый доступ.

Сборки публикуются отдельно по мере готовности. Пакеты пока не имеют доверенной подписи Windows и Apple Developer ID.
