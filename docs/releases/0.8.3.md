# Архив ЖЖ 0.8.3

- Исправлен вход для закрытых фотографий ЖЖ. Токен API и cookie фотохостинга имеют разные форматы. При отказе доступа приложение выполняет обычный веб-вход и повторяет загрузку с cookie, выданными ЖЖ. Пароль передаётся только ЖЖ по HTTPS; пароль и cookie не записываются на диск.
- Ранее закрытые ошибки 403, полученные только с токеном API, снова доступны для докачки. Если веб-вход не подтверждён, файл остаётся ожидающим входа, а не считается отсутствующим.
- При загрузке отдельного изображения виден текущий этап входа. Диагностика различает API и веб-сессию, общее число попыток и число запросов последней попытки; значения cookie в неё не попадают.
- «Докачать пропуски» и «Продолжить» проверяют свежие записи. Для всего журнала и периода обновляется календарь, загружаются новые и изменившиеся дни с комментариями к новым постам. Неизменившиеся дни и уже полученные обсуждения повторно не скачиваются. Режим по URL остаётся ограничен выбранными ссылками.

Запустите новую версию и нажмите «Загрузить» у недостающей фотографии или «Докачать пропуски» у архива. При запросе пароля введите его в приложении. Проверка конкретной закрытой фотографии требует входа владельца; автоматические тесты используют локальные ответы сервера.

Пакеты Windows, macOS и Linux появляются по мере завершения сборок и проверки запуска. Пакеты пока не имеют доверенной цифровой подписи Windows и Apple; порядок запуска описан в [руководстве](https://github.com/vladfedin/journal-archive/blob/main/docs/guide/README.md).
