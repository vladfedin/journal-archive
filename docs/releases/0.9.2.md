# Архив ЖЖ 0.9.2

- На странице «Архивы» у каждого журнала своя карточка с хронологией. Шкала показывает всю историю по годам, а рамка на ней — записи, которые видны в ленте ниже. Рамку можно тянуть, по шкале и подписям лет можно щёлкать. Первая карточка раскрыта, остальные раскрываются щелчком по шкале.
- Пока идёт загрузка, на месте карточки журнала видны её этап, ход и хронология полученных записей. Когда загрузка закончится, карточка снова станет обычной и покажет «обновлён только что» и время загрузки.
- В карточке видны годы, число записей, комментариев, изображений и видео, а также сколько обсуждений и изображений недоступно. Раздел «Что не удалось получить» перечисляет причины по отдельности, включая изображения, которых нет в ЖЖ или к которым закрыт доступ. Если пропуски ещё можно докачать, рядом есть кнопка «Докачать».
- Разделы архива, ZIP и JSON, параметры загрузки, изображения, состояние архива и диагностика собраны в меню «⋯» карточки вместо «Технических сведений».
- На телефоне вертикальное движение пальцем по шкале прокручивает страницу, а сдвиг в сторону двигает рамку.

Обновление доступно из раздела «Архивы» → «Обновления приложения». Пакеты Windows и macOS распространяются без цифровой подписи издателя.
