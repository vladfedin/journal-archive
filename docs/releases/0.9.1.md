# Архив ЖЖ 0.9.1

- В ленте поиск и фильтры открываются кнопками в строке разделов. На узком экране разделы сворачиваются до иконок. Рядом с именем журнала вернулся привычный значок пользователя ЖЖ.
- В записях и комментариях теперь системный шрифт без засечек. Увеличены даты, счётчики комментариев и подписи календаря.
- Календарь показывает «Есть пропуски» только в годах с отмеченными днями. Если за выбранный период известно число недополученных записей, рядом со списком появляется ссылка на отчёт. При просмотре комментариев видно, что они сгруппированы по дате записи.

Обновление доступно из раздела «Архивы» → «Обновления приложения». Пакеты Windows и macOS распространяются без цифровой подписи издателя.
