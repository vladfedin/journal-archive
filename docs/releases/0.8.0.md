# Архив ЖЖ 0.8.0

- Архивирование управляемых сообществ: в «Новом архиве» выберите «Моё сообщество», укажите его имя и войдите личным аккаунтом владельца или смотрителя.
- Поддерживаются весь журнал, период, тестовая выгрузка, продолжение и обновление по ссылкам. Записи и комментарии сохраняются с исходными авторами, маркировкой доступа, реакциями и выбранными материалами.
- Аккаунт для входа отделён от журнала в параметрах задачи, SQLite, JSON и ActivityStreams. Личный профиль и переписка аккаунта в архив сообщества не включаются. В ActivityStreams сообщество представлено как Group, авторы сообщений — как Person.
- Права управления проверяются при входе. Обычное участие, право публикации или модерации не считаются подтверждением полного доступа. При отказах и неполных ответах архив не отмечается полным; сохранённые тексты остаются на месте.

Проверки выполнены на тестовых ответах протокола, включая несколько авторов, скрытые комментарии, отказ доступа и продолжение. Подтверждённой проверки на реальном управляемом сообществе для этого выпуска пока нет. Если ЖЖ изменил страницу управления или протокол, приложение сообщит, что не смогло подтвердить права.

Пакеты для Windows, macOS и Linux появляются здесь по мере завершения сборки и проверки запуска. Архивы хранятся отдельно от приложения. Пакеты пока не имеют доверенной цифровой подписи Windows и Apple; порядок запуска описан в [руководстве](https://github.com/vladfedin/journal-archive/blob/main/docs/guide/README.md).
