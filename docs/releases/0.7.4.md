# Архив ЖЖ 0.7.4

В форме создания и обновления архива появилась настройка «Скачать видео». Поддерживаются вставки ЖЖ `lj-embed`, YouTube, VK Video, Vimeo и прямые видеофайлы. Вставки, адрес которых ещё не получен, остаются видимыми ссылками на оригинальную запись.

Видео сохраняются в `media` и воспроизводятся внутри постов и комментариев, в том числе без запущенного приложения. Сохраняется положение относительно `lj-cut`. Локальный сервер поддерживает перемотку через HTTP Range. Исходные адреса, названия, статусы и пути входят в JSON; ActivityStreams содержит вложения `Video`.

Запросы метаданных, перенаправления, скачивание и повторы используют общий лимит и паузы. Незаконченные файлы продолжаются с сохранённой позиции, готовые повторно не скачиваются. Причины отказов доступны в состоянии архива. Внешним видеосервисам не передаются учётные данные ЖЖ. FFmpeg и Deno входят в сборку; отдельно устанавливать их не нужно.

В статистике добавлены две верхние строки: все комментарии по году комментария и опубликованные записи по году публикации, включая записи без обсуждений. Итоги не зависят от поиска участника и переключения показателя. Числа открывают соответствующий список записей и комментариев.

Для загрузки видео из старого поста выберите «Обновить → По ссылкам», укажите URL записи и включите «Скачать видео». «Продолжить» использует настройки ранее запущенной задачи.

Сборки публикуются отдельно по мере готовности.
