# Архив ЖЖ 0.8.7

- Исправлен запуск Chrome/Edge на Windows: приложение дожидается освобождения служебного файла браузера. Ошибка была обнаружена проверкой релизного пакета 0.8.6; Windows-пакет той версии не публиковался.
- Включены возможности 0.8.6: загрузка изображений ЖЖ через отдельное окно Chrome/Edge, пакетная докачка только отсутствующих файлов, адреса и цепочки ответов, сохранение HTML/JSON и пересчёт пропусков. У изображения — «Через браузер»; для всего архива — «Изображения: файлы и докачка».
- Релизы используют уже проверенные пакеты точного коммита тега, без повторной сборки. Контрольные суммы сверяются перед публикацией.

Войдите в ЖЖ в открытом окне браузера, затем нажмите «Продолжить» в приложении. Вход хранится в отдельном сеансе до завершения приложения. Нужен установленный Chrome или Edge; браузер не входит в размер пакета.

Проверки с настоящим Chromium покрывают вход и получение защищённых PNG, HTTP-ошибки, лимит, отмену, сохранение файлов и интерфейс. Доступность закрытых файлов конкретного журнала проверяется только в сеансе его владельца.

Windows: скачайте EXE и запустите. Архивы и прогресс используются из прежней папки. Пакеты пока без доверенной подписи Windows и Apple Developer ID/notarization.
