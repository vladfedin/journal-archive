# Архив ЖЖ 0.9.4

- В профиле видны основной юзерпик, подписи к картинкам и ссылка на оригинал в ЖЖ. Биография сохраняет форматирование. Интересы, юзерпики и длинные списки можно раскрывать по мере чтения.
- Друзья, добавившие вас в друзья, подписки и подписчики показаны отдельно. Для сообществ видно, какие вы читаете, в каких состоите и какими управляете. Поиск ведёт к соответствующему списку.
- В старом архиве откройте **Профиль → Данные архива → Обновить профиль**, чтобы получить подписки и сведения об управлении. Повторно скачивать записи для этого не требуется. При прерывании уже полученные имена сохраняются.

Пакеты Windows и macOS распространяются без цифровой подписи издателя.
