# Архив ЖЖ 0.8.1

- Загрузка изображений ЖЖ использует авторизованную сессию: при выгрузке журнала и по кнопке «Загрузить» в записи. Старые HTTP-ссылки на серверы изображений ЖЖ запрашиваются по HTTPS.
- Вход, выполненный в приложении, доступен для последующих загрузок материалов в течение часа. Сессия хранится только в памяти и удаляется при завершении приложения. После перезапуска или отказа доступа кнопка загрузки закрытого изображения предложит ввести пароль.
- Исправлена блокировка очереди материалов при обновлении страниц архива. Состояние загрузки и отмена остаются доступны; работа с другим архивом не задерживает выбранное изображение.
- В отчёте об ошибке изображения отмечается, был ли запрос отправлен с авторизацией. Значения cookie и пароль в архив, отчёт и параметры задачи не записываются. Cookie не передаются сторонним серверам, в том числе при перенаправлениях.
- Число автоматических попыток запроса к API ЖЖ уменьшено до четырёх.

Авторизованная загрузка проверена на тестовом серверном ответе, включая 403 без сессии, повторный вход, сохранение файла и перенаправления. Получение конкретного закрытого изображения в реальном аккаунте требует проверки после входа пользователя в приложение.

Запустите новый файл и нажмите «Загрузить» у недостающего изображения. Если приложение попросит пароль, введите его в форме под изображением. Уже сохранённые записи повторно скачивать не нужно.

Пакеты Windows, macOS и Linux появляются по мере завершения сборок и проверки запуска. Архивы пользователей хранятся отдельно. Пакеты пока не имеют доверенной цифровой подписи Windows и Apple; порядок запуска описан в [руководстве](https://github.com/vladfedin/journal-archive/blob/main/docs/guide/README.md).
