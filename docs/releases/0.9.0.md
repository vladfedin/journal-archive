# Архив ЖЖ 0.9.0

- Лента подгружает записи при прокрутке. Вернуться из записи или комментария можно на прежнее место с теми же фильтрами и сортировкой. Лента работает и при открытии архива с диска.
- Закреплённая запись ЖЖ отображается первой в общей ленте. В календаре она остаётся на дате публикации.
- Поиск, фильтры и переключатель «Кратко / Полностью» занимают меньше места. На телефоне фильтры расположены в два столбца.
- «Открыть архив» и «Статистика» находятся рядом с названием журнала. Состояние архива, докачка пропусков, параметры и диагностика собраны в «Технических сведениях». У разделов и кнопок появились иконки Lucide.
- На [зеркале загрузок](https://staerum.ru/journal-archive/) доступны пакеты, контрольные суммы и описание изменений каждой версии.

Для обновления откройте «Архивы» → «Обновления приложения» или скачайте пакет для своей системы. У сборок Windows и macOS пока нет цифровой подписи издателя.
