# Архив ЖЖ 0.7.5

Исправлена подмена «Всех записей» хронологией во время загрузки. По адресу `index.html` всегда открываются записи, в том числе до завершения первой выгрузки. Полная лента показывает уже полученные тексты и материалы; хронология остаётся отдельной страницей. Чтение не останавливает и не изменяет текущую задачу.

Добавлен отдельный календарь: двенадцать месяцев выбранного года, число записей в каждом дне и итоги по месяцам. Нажатие на день или месяц открывает соответствующие посты в ленте. Календарь использует дату публикации в журнале, без сдвига часового пояса; дни без записей остаются пустыми.

Между записями, календарём, хронологией и статистикой можно переключаться ссылками на странице. По умолчанию открывается полная лента; выбранный пользователем краткий режим запоминается. Все три представления работают при открытии архива с диска.

Обновление оформления существующего архива выполняется локально. Повторно скачивать журнал для появления календаря не нужно. Если в старой версии сейчас идёт выгрузка, её можно закончить перед запуском нового EXE. При обновлении приложения во время работы прогресс сохраняется; затем нажмите «Продолжить».

Сборки публикуются отдельно по мере готовности.
