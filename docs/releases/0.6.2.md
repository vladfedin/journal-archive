# Архив ЖЖ 0.6.2

Исправлен запуск новой версии поверх работающей старой. Раньше свежий exe открывал существующий процесс без проверки версии — поэтому на странице оставалось «0.3.0».

- Новый запуск проверяет версию работающего приложения. Старый процесс завершается штатно; новый открывает ту же папку архивов на том же адресе.
- Если шла загрузка, приложение сначала сохраняет прогресс. После обновления нажмите «Продолжить» и введите пароль.
- Повторный запуск той же версии открывает её окно. Уже работающая более новая версия не заменяется старой.
- Если завершение затянулось, появляется понятное сообщение; второй процесс с той же базой не запускается.
- Добавлены проверки обновления с протокола 0.3.0 для готовых пакетов Windows, macOS и Linux.

**Windows:** скачайте `JournalArchive-0.6.2-windows-x64.exe` и запустите. Если пока используете 0.6.1, завершите старую версию кнопкой «Завершить приложение» внизу страницы и повторно запустите новый exe. Закрытие вкладки браузера само приложение не закрывает.

Файлы архивов находятся отдельно от exe и сохраняются при обновлении. Пакеты не подписаны цифровым сертификатом; рядом с каждым файлом опубликована SHA-256.
