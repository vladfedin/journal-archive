### Экспорт ActivityStreams 2.0

**Скачать JSON** теперь выдаёт ActivityStreams 2.0: записи, дерево ответов, авторов, реакции и изображения. Особенности ЖЖ сохранены в документированных расширениях.

В тот же файл включён полный исходный снимок с контрольной суммой: права доступа, скрытые комментарии, исходная разметка, история изменений, неизвестные поля и сведения о пропусках. Проверяется точное обратное преобразование, в том числе через независимый JSON-LD 1.0 процессор. **Исходный JSON** остаётся доступен отдельно; прежние файлы и CLI-команды совместимы.

Новый формат создаётся локально из уже сохранённых данных, без входа в ЖЖ. ZIP содержит оба JSON, страницы, скачанные медиа и копию стандартного контекста. [Описание формата и расширений](https://github.com/vladfedin/journal-archive/blob/main/docs/activitystreams.md).

### Пакеты

Windows x64: запустите EXE. macOS Apple Silicon / Intel: распакуйте соответствующий ZIP и откройте приложение. Linux x64: распакуйте TAR.GZ и запустите `LiveJournalArchive`. Python устанавливать не нужно.

Пакеты без доверенной подписи Windows и Apple Developer ID/notarization. Контрольные суммы `.sha256` приложены.
