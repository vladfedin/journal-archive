# Архив ЖЖ 0.8.14

Полнотекстовый поиск находит записи, комментарии, переписку, сведения профиля и материалы. Искать можно в одном журнале или сразу во всех архивах. Результаты можно отфильтровать по автору и году.

На странице состояния архива появились «Подробности проверки» со ссылками на пропущенные материалы и записи. Удалённые комментарии распознаются по отметкам ЖЖ. Если текст уже попал в архив до удаления, его сохранённая версия остаётся доступной.

При запуске копирования и после его завершения можно написать автору приложения. Введите текст и нажмите «Отправить». Получатель — staerum, отправитель — аккаунт, которым вы вошли в ЖЖ для выгрузки. Форма также доступна со страницы «Архивы» и из «Помощи».

Для видео ЖЖ из комментариев архив открывает ветку обсуждения с нужным плеером. Ссылка «Видео в оригинале» также ведёт к комментарию.

Настольное приложение проверяет наличие новых версий. На странице «Архивы» можно включить автоматическую загрузку. После проверки пакета новая версия запускается при следующем открытии приложения.

Для перехода с 0.8.13 и более ранних версий скачайте пакет для своей системы. У сборок Windows и macOS пока нет цифровой подписи издателя.
