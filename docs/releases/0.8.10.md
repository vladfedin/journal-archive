# Архив ЖЖ 0.8.10

- При докачке через браузер карточка показывает текущий адрес, последний результат и числа сохранённых и недоступных изображений.
- Если браузер получает HTTP 403, 404 или 410 по адресу самого изображения, архив сохраняет ссылку и ответ сервера. Очередь продолжает работу. Старые архивы учитывают такой ответ без нового запроса. Отдельную картинку можно проверить снова из записи.
- Карточка завершённой выгрузки показывает отдельно видео, если его начали загружать вручную при выключенной опции скачивания видео.
- В галерее появилась непрерывная сетка изображений с фильтром по тегам. Наведение открывает увеличенное превью, нажатие — просмотр с перелистыванием.

В Windows запустите новый EXE. Для входа через браузер нужен Chrome или Edge. Пакеты распространяются без доверенной подписи Windows и Apple.
