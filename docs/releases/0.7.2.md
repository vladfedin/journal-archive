# Архив ЖЖ 0.7.2

Исправлена статистика для дат комментариев вида `2005-04-18 04:15:04 UTC`: ранее такие комментарии попадали в общие количества, но не распределялись по годам. Исправление также восстанавливает датированные связи, возвращения участников и ожившие обсуждения. ActivityStreams корректно получает `published` для этих дат; исходные значения остаются без изменений.

Таблица участников использует пять оттенков зелёного: ненулевые значения видны даже рядом с большими числами. Шкала логарифмическая, стабильная при поиске и переключении страниц. Имена и итоговые значения закреплены при горизонтальной прокрутке; ширина годовых колонок адаптируется к экрану. Поддерживаются светлая и тёмная темы.

Ссылки «ЖЖ ↗» и «Оригинал ↗» открываются в отдельной вкладке. Подсказка хронологии различает полноту комментариев и загрузку изображений, показывает число скрытых комментариев. На странице записи появляется конкретная причина неполноты, например «Не загружены изображения: 3». Неполученные изображения по-прежнему считаются пропусками; наличие сохранённого скрытого комментария не является ошибкой.

Существующий архив пересобирается из локальных данных при открытии в новой версии. Повторно скачивать комментарии для исправления статистики не требуется.

Сборки публикуются отдельно по мере готовности. Файлы пока без цифровой подписи.
