# Архив ЖЖ 0.9.7

- Новый источник **Другой журнал** — архив чужого журнала или сообщества. Войдите в ЖЖ своим аккаунтом и укажите имя журнала: в архив попадут записи и обсуждения, которые разрешено читать этому аккаунту. Комментарии можно не загружать. У каждого читателя своя папка архива.
- Если ЖЖ отдал читателю не все комментарии к записи, обсуждение отмечается как неполное. Записи, которые ЖЖ перестал возвращать, перечислены в отчёте, а их сохранённый текст остаётся в архиве.
- Обновление архива сообщества за период читает новые публикации и сам период, а не всю ленту сообщества.
- Если имя журнала введено с ошибкой, пустой архив не создаётся.

Пакеты Windows и macOS распространяются без цифровой подписи издателя.
