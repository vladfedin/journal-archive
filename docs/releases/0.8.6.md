# Архив ЖЖ 0.8.6

- Изображения ЖЖ можно загружать через установленный Chrome или Edge. Кнопка «Через браузер» открывает отдельное окно для входа; после «Продолжить» приложение получает файл в этом же сеансе и сохраняет его в архиве.
- «Изображения: файлы и докачка» показывает отсутствующие файлы, ответы серверов и ссылки на записи. Общая докачка через браузер запрашивает только эти изображения. Сохранённые файлы пропускаются, записи и комментарии заново не загружаются.
- Для запросов сохраняются способ загрузки, адрес без параметров авторизации, HTTP-ответ и время. Отмена и достижение лимита сохраняют уже полученные ответы. После загрузки пересчитывается список пропусков; изображения появляются в HTML и JSON.
- Автоматическая загрузка соблюдает паузу между файлами, общий лимит и `Retry-After`. Отказ доступа в браузере возвращает к проверке входа в том же окне. Вход не копируется из повседневного профиля и не записывается в архив.

Проверен сквозной сценарий с настоящим Chromium и локальным сервером: вход, защищённые PNG, перенаправления, HTTP 403/404/429, лимит, отмена, сохранение HTML/JSON и повторное открытие. Это не подтверждение доступности каждого закрытого файла в конкретном журнале: такой файл проверяется в сеансе его владельца.

Windows: скачайте EXE и запустите. macOS: распакуйте ZIP и откройте приложение. Linux: распакуйте архив и запустите `LiveJournalArchive`. Архивы и сохранённый прогресс используются из прежней папки. Для нового способа загрузки нужен установленный Chrome или Edge; браузер не добавлен в размер пакета.

Пакеты пока без доверенной подписи Windows и Apple Developer ID/notarization. Инструкции запуска находятся в помощи приложения.
