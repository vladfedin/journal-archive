# Архив ЖЖ 0.8.4

- Исправлена остановка загрузки списков отреагировавших на закрытых записях. Приложение получает служебный токен на основном сайте ЖЖ, без перехода на страницу первого недогруженного поста. Запросы списков используют сессию вошедшего пользователя.
- При остановке на реакциях карточка архива показывает причину. В диагностику добавлены число полученных, ожидающих и недоступных списков, а также HTTP-статус перенаправления. Имена пользователей, токены и адреса переходов в диагностику не включаются.
- Докачка сохраняет полученные ранее списки и счётчики. Как и в 0.8.3, при продолжении всего журнала или периода проверяется календарь новых записей; сохранённые обсуждения повторно не скачиваются.

Если внизу страницы осталась старая версия, нажмите «Завершить приложение» и запустите новый файл. После запуска внизу должно быть **0.8.4**. Затем выберите «Докачать пропуски».

Получение списка через основной сайт проверено на публичной записи. Закрытые записи проверяются локальными тестами с имитацией ответов ЖЖ; проверка реального архива требует входа владельца.

Пакеты Windows, macOS и Linux появляются по мере завершения сборок и проверки запуска. Пакеты пока не имеют доверенной цифровой подписи Windows и Apple; порядок запуска описан в [руководстве](https://github.com/vladfedin/journal-archive/blob/main/docs/guide/README.md).
