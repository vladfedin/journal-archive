# Архив ЖЖ 0.8.13

Для команды «Через браузер» приложение открывает отдельный профиль Chrome или Edge для каждого аккаунта ЖЖ. При первом входе выберите «Запомнить меня», если ЖЖ предлагает такой выбор. При следующих запусках достаточно подтвердить аккаунт в открывшемся окне, пока вход действует. Выйти можно в том же окне ЖЖ.

Профили хранятся на этом компьютере отдельно от папки архивов.
