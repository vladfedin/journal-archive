# Архив ЖЖ 0.7.3

- Отказ 401/403 при скачивании одного изображения больше не блокирует остальные файлы на том же сервере. Паузы, повторы временных ошибок и общий лимит запросов сохраняются.
- Причины недоступности изображений сохраняются между запусками и пересборками: HTTP-код, ошибка соединения, прерванная загрузка, лимит запросов. Они доступны в подробностях состояния архива, исходном JSON и его представлении в ActivityStreams. Для старых пропусков без диагностики причина не придумывается.
- При открытии архива старой версии сразу появляется экран подготовки: обработанные записи и текущий этап пересборки. Запросы к ЖЖ для этого не выполняются.
- В карточке загрузки, меню архива и подробностях появилась ссылка на статистику.
- Числа в таблице участников открывают список всех подходящих записей и комментариев с датами и выдержками. Можно перейти к записи или конкретному комментарию; возврат сохраняет выбор участника и года. Работает и при открытии архива с диска.
- Процентная таблица использует ту же ширину колонок, что и обычные количества: знак процента показан под числом. На узких экранах сохраняются прокрутка и закреплённые имена.

После запуска новой версии откройте архив для обновления страниц. Для дозагрузки пропущенных изображений нажмите «Продолжить».

Сборки публикуются отдельно по мере готовности.
