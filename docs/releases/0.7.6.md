# Архив ЖЖ 0.7.6

Отдельные изображения и видео можно загрузить прямо из записи или полной ленты. Нажмите «Загрузить» рядом с отсутствующим материалом: файл появится на странице и сохранится для последующих просмотров. Обновляются HTML, JSON, ActivityStreams и отчёт; тексты постов и комментариев не изменяются.

Видны очередь, ожидание повторов и причины ошибок. Загрузку можно отменить и повторить. Очередь ждёт завершения основной выгрузки, работает последовательно и соблюдает сохранённые паузы сервиса. Если общий предел не задан, отдельная ручная загрузка ограничена 50 запросами с учётом повторов; обычная выгрузка остаётся без такого ограничения.

Распознаются вставки через оболочку lj-embed, включая Яндекс Музыку. Для неё сохраняется адрес и доступен «Онлайн-плеер» по нажатию; аудиофайл не объявляется сохранённым. Временные токены ЖЖ не попадают в архив. Для закрытых вставок можно ввести пароль в приложении.

Откройте старый архив через новую версию: оформление обновится локально. Если выгрузка ещё идёт, дождитесь её окончания перед сменой EXE. Загруженные материалы доступны и при открытии архива с диска; новые загрузки работают через запущенное приложение.

Сборки публикуются отдельно по мере готовности.
