# Архив ЖЖ 0.8.8

- Недоступное изображение с ответом HTTP 401, 403 или 404 больше не останавливает браузерную докачку остальных файлов. После первого прохода выполняются два повтора; оставшиеся отказы сохраняются в отчёте и не требуют бесконечно продолжать загрузку.
- Основная кнопка «Докачать пропуски» открывает вход через Chrome/Edge, если предыдущая загрузка изображений остановилась на авторизации. После входа нажмите «Продолжить» в карточке архива. Продолжается та же задача, включая проверку свежих записей.
- Если браузер действительно потерял сеанс и вернул страницу входа, приложение предлагает войти повторно. Отказ в доступе к отдельному файлу не считается потерей сеанса.
- Исправлен показ старого результата браузерной докачки поверх результата новой загрузки.

Нужен установленный Chrome или Edge. Архивы и прогресс используются из прежней папки. Windows: скачайте новый EXE и запустите. Пакеты пока без доверенной подписи Windows и Apple Developer ID/notarization.
