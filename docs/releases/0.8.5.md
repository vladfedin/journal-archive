# Архив ЖЖ 0.8.5

- Исправлена передача авторизации при переходах между сервером изображений и основным сайтом ЖЖ. Новые cookie сохраняются в памяти на протяжении цепочки; повторяющиеся переходы прекращаются, остальные ранее выявленные запросы на вход пропускаются до нового запуска. Ответы HTTP 302 больше не показываются как «ЖЖ не отвечает».
- Видео самого ЖЖ больше не исчезают из архива: распознаются старые числовые ID и новые `record::UUID`. Загрузка использует текущий плеер и проверку доступа ЖЖ, сохраняет MP4 со звуком и учитывает каждый запрос к сегментам. Токены не сохраняются. Проверено скачивание реального ролика ЖЖ и ролика YouTube.
- «Материалы»: галерея изображений, видео и юзерпиков с фильтрами и страницами. Изображение ведёт к посту или комментарию; для повторяющегося материала доступны все места использования. Есть открытие файла и докачка через приложение.
- «Профиль»: читаемые сведения, друзья, подписки, юзерпики и сохранённые настройки. Кнопка «Загрузить профиль» запускает отдельную задачу с вводом пароля, без повторного обхода постов и комментариев. Частичные результаты и причины ошибок видны на странице. Неполный ответ сохраняет ранее полученные списки с отметкой; после успешной загрузки старая причина неполноты снимается.
- Общая карта хронологии по умолчанию учитывает реальные даты. Если публикации начались в октябре, январь–сентябрь остаются пустыми. Плотность отражена насыщенностью; можно переключиться на равную ширину каждой записи.

После запуска новой версии откройте архив через приложение: оформление обновится автоматически. Для личных данных откройте «Профиль» → «Загрузить профиль». Для видео выберите материал в посте или галерее либо включите «Скачать видео» в параметрах выгрузки.

Пакеты Windows, macOS и Linux публикуются по мере готовности. Пакеты пока не имеют доверенной цифровой подписи Windows и Apple; порядок запуска описан в [руководстве](https://github.com/vladfedin/journal-archive/blob/main/docs/guide/README.md).
