# Архив ЖЖ 0.7.8

- Хронология: тонированные полосы лет на общей карте, подписи годов, связанная рамка и подробная шкала. Обзор объединяет плотные группы записей, сохраняя цвет пропусков. В подробной шкале каждый столбик открывает отдельный пост; есть переходы по годам, стрелки и клавиатурная навигация. Проверены 300 и 500 записей в год, до 10 000 записей за 20 лет.
- **Докачать пропуски**: перед запуском виден состав недостающего. Во время работы и в результате — **Было / Закрыто / Осталось**, отдельно новые пропуски и причины ошибок. История последних запусков сохраняется после закрытия приложения. После ручной остановки действие называется **Продолжить**.
- При автоматическом повторе видны номер попытки, время окончания паузы и номер прохода докачки. Чтение списка пропусков выполняется в фоне и не задерживает обновление статуса.

Докачка использует сохранённый этап и параметры, включая лимит запросов. Успех определяется по конкретным пропускам, а не по разнице общих сумм. Число неполных обсуждений не выдаётся за число недостающих комментариев. Удалённые комментарии, перепосты и намеренно выключенная загрузка видео не становятся ошибками докачки.

Сборки публикуются отдельно по мере готовности. Пакеты пока не имеют доверенной подписи Windows и Apple Developer ID.
