Первый выпуск с новым интерфейсом и самостоятельными приложениями для четырёх платформ.

### Скачать и запустить

| Файл | Запуск |
|---|---|
| `JournalArchive-0.3.0-windows-x64.exe` | Откройте EXE. |
| `JournalArchive-0.3.0-macos-arm64.zip` | Apple Silicon: распакуйте, откройте `LiveJournalArchive.app`. |
| `JournalArchive-0.3.0-macos-x64.zip` | Intel Mac: распакуйте, откройте `LiveJournalArchive.app`. |
| `JournalArchive-0.3.0-linux-x64.tar.gz` | Распакуйте, запустите `LiveJournalArchive`. |

Python устанавливать не нужно. Откроется локальная страница в браузере. Нажмите **Новый архив** и введите имя и пароль ЖЖ. Инструкция — в разделе **Помощь**, она также входит в скачиваемый архив.

### В этом выпуске

- Список архивов, компактные страницы записей и комментариев, светлая и тёмная темы.
- Весь журнал по умолчанию, период или тест последних 10 записей. Обычная выгрузка без общего лимита запросов; тест — до 50. Настраиваемые паузы и лимит.
- Одна команда **Обновить**: за период, по ссылкам или весь журнал с проверкой целостности.
- Продолжение после остановки и перезапуска с сохранёнными параметрами. Пароль на диск не записывается.
- Реакции с авторами, поиск по комментариям, сворачиваемые ветки, экспорт JSON и ZIP, автономная помощь.
- Старые архивы получают новое оформление без сетевой загрузки при открытии или скачивании ZIP.

### Проверки и ограничения

Пакеты собираются и запускаются на Windows Server 2022 x64, macOS 15 (Apple Silicon и Intel), Ubuntu 22.04 x64. На каждой платформе проходят тесты загрузчика и нативного приложения; отдельно проверяется интерфейс в Chromium, включая ширину 320 px и чтение через `file://`. Для Linux требуется glibc 2.35 или новее.

Тесты используют вымышленные данные и моделируемые ответы ЖЖ. Полная загрузка реального журнала за 20 лет этим выпуском не проверена. Приложение сохраняет доступные владельцу данные; если ЖЖ не отдаёт часть текстов, реакций или авторов, архив останется с отметкой о пропусках. Постоянный отказ в доступе требует вмешательства пользователя.

**Подпись:** пакеты не имеют доверенной подписи Windows и Apple Developer ID/notarization. Windows может показать SmartScreen, macOS — запрос подтверждения неизвестного разработчика. На Mac после первой попытки запуска разрешение доступно в «Системные настройки → Конфиденциальность и безопасность», если это допускается политиками компьютера. [Инструкция Apple](https://support.apple.com/102445). Отключать защиту системы не требуется.

Рядом с каждым пакетом находится файл `.sha256` для проверки скачивания. Архивы пользователей в дистрибутивы не включены. Для переноса существующей работы скопируйте всю папку архивов с SQLite и `.jobs`; ZIP для чтения не содержит рабочую базу.
