В шапке журнала добавлена ссылка **← Архивы**, возвращающая к общему списку архивов. Она доступна в локальном приложении на страницах журнала, записей, помощи и состояния. В автономном ZIP навигация остаётся внутри журнала.

Для возврата без обновления откройте `http://127.0.0.1:8787/` (если при запуске выбран другой порт, используйте его).

Windows x64: запустите EXE. macOS Apple Silicon / Intel: распакуйте соответствующий ZIP и откройте приложение. Linux x64: распакуйте TAR.GZ и запустите `LiveJournalArchive`. Пакеты появляются по мере готовности каждой платформы.

Пакеты без доверенной подписи Windows и Apple Developer ID/notarization. Контрольные суммы `.sha256` приложены.
