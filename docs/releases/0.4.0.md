### В этом выпуске

- **Кратко / Полностью**: краткий список или полная лента записей с изображениями и юзерпиком в углу. Режим запоминается; полные тексты подгружаются по страницам и работают без сервера.
- **`lj-cut`** раскрывается прямо в ленте. На странице отдельной записи скрытая часть открыта сразу. Исходная разметка остаётся в JSON.
- **Юзерпики** сохраняются для конкретной записи или комментария и отображаются в автономном архиве. Повторяющиеся картинки скачиваются один раз. Юзерпики загружаются автоматически, изображения внутри постов — по флажку «Скачать изображения».
- **Повторная загрузка пропусков**: до трёх проходов с паузами 30 и 60 секунд для неполных успешных ответов. Завершённые обсуждения и полученные счётчики не скачиваются повторно. Сетевые ошибки по-прежнему имеют до шести попыток с увеличением задержки и соблюдением `Retry-After`.
- Недоступные картинки и неопределённые юзерпики учитываются в состоянии задачи. После остановки можно продолжить; общий лимит запросов внутри запуска не сбрасывается.

### Обновление существующего архива

Оформление обновится при открытии архива или скачивании ZIP. Для юзерпиков выберите **Обновить → Весь журнал** либо нужный период: старые выгрузки не запрашивали адреса картинок комментариев. Понадобится вход в ЖЖ. Данные и оригинальная разметка сохраняются; JSON дополнен разделом `userpics` с адресами, локальными путями и способом определения картинки.

### Пакеты

- Windows x64: запустите `JournalArchive-0.4.0-windows-x64.exe`.
- Mac Apple Silicon / Intel: распакуйте соответствующий ZIP и откройте `LiveJournalArchive.app`.
- Linux x64: распакуйте TAR.GZ и запустите `LiveJournalArchive` (glibc 2.35+).

Python устанавливать не нужно. Сборки проверяются запуском на Windows Server 2022, macOS 15 Apple Silicon/Intel и Ubuntu 22.04; интерфейс — в Chromium, включая `file://` и ширину 320 px. Тесты загрузки моделируют неполные ответы, восстановление и лимиты. Дополнительно проверен реальный ответ ЖЖ с юзерпиками открытых комментариев.

Пакеты без доверенной подписи Windows и Apple Developer ID/notarization. ОС может запросить подтверждение неизвестного разработчика; [инструкция Apple](https://support.apple.com/102445). Контрольные суммы `.sha256` приложены.

Удалённые картинки и данные, которые ЖЖ не возвращает владельцу, восстановить нельзя. Постоянные отказы в доступе не запускают бесконечные повторы. При выбранном ключевом слове, которое не удалось найти, чужой или основной юзерпик не подставляется.
