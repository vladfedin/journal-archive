# Архив ЖЖ 0.9.6

- При выгрузке без лимита запросов архив проверяет закреплённую запись сразу после входа. Если загрузка обсуждений или видео прервётся, уже подтверждённый закреп сохранится в ленте.
- Записи и комментарии скачиваются раньше изображений и видео. Если один сервер материалов просит подождать, архив может продолжить загрузку с другого.
- В окне создания архива можно повторно выбрать сообщество из сохранённого списка или обновить список вручную.
- Нажмите на строку загрузки, чтобы посмотреть запросы, ответы, ожидание и повторные попытки.
- В шапке приложения выровнены значок архива и название.

Пакеты Windows и macOS распространяются без цифровой подписи издателя.
