# Архив ЖЖ

Локальное приложение для выгрузки своего Живого Журнала: записи, комментарии, реакции и их авторы. Архив читается без приложения и интернета; данные доступны отдельно в JSON.

**[Скачать для Windows, macOS или Linux](https://github.com/vladfedin/journal-archive/releases/latest)**

## Запуск

- Windows x64: запустите `.exe`.
- Mac: распакуйте ZIP для Apple Silicon или Intel, откройте `LiveJournalArchive.app`.
- Linux x64: распакуйте TAR.GZ, запустите `LiveJournalArchive`.

Python устанавливать не нужно. Приложение откроет локальную страницу в браузере. Статус подписи и требования конкретных пакетов указаны в описании выпуска.

Нажмите **Новый архив**, введите имя и пароль ЖЖ, выберите объём: **Весь журнал**, **За период** или **Тест (последние 10 записей)**. Пароль не записывается на диск. Юзерпики записей и комментариев скачиваются автоматически; изображения внутри текстов — по отдельному флажку.

В меню архива **⋯ → Обновить** доступны период, ссылки на старые записи/комментарии и весь журнал с проверкой целостности. Даты ограничивают публикацию записей; комментарии к ним загружаются за всё время. Число лет не ограничено.

Приложение делает запросы последовательно, с паузами. Временные ошибки повторяются с увеличением задержки; `Retry-After` соблюдается. Для неполных успешных ответов предусмотрено до трёх проходов по пропускам, с паузами 30 и 60 секунд. После остановки можно продолжить с сохранённых этапов, в том числе после перезапуска приложения. Постоянный отказ в доступе или исчерпание повторов потребуют действия пользователя. Обычная выгрузка не имеет общего лимита запросов; тест ограничен 50. Свой лимит задаётся в настройках.

В архиве можно переключиться между кратким списком и полной лентой записей. В полной ленте видны текст, сохранённые изображения и юзерпик; `lj-cut` раскрывается на месте. Оба режима работают без сервера.

**Помощь** в приложении — одна страница с инструкциями; она же входит в автономный архив.

Загрузка показана на хронологии: сначала календарь, затем записи с комментариями и материалами. Столбики открывают сохранённые записи; подсказки показывают объём и активных комментаторов. Карта сохраняет смысл после остановки и доступна в меню архива.

Опция **Профиль, друзья, настройки, юзерпики** сохраняет доступные личные данные; **Личная переписка** отдельно добавляет входящие и исходящие из серверного inbox, не меняя статус прочтения. Это не гарантирует сохранность сообщений, которые ЖЖ уже не выдаёт. [Состав и границы экспорта](docs/json-format.md#личные-данные-приложение-060).

## Обновление приложения

Запустите новый скачанный файл. Начиная с 0.6.3 он проверяет работающую версию, штатно завершает старую и открывает ту же папку архивов. Если в этот момент шла загрузка, её прогресс сохраняется; после обновления нажмите **Продолжить** и введите пароль.

Если версия на странице осталась старой при запуске пакета 0.6.2 или ниже, нажмите **Завершить приложение** внизу страницы, затем снова запустите новый файл. Закрытие вкладки браузера не завершает процесс. Готовый exe — отдельное приложение, не установщик: старые скачанные файлы и ярлыки автоматически не заменяются.

## Данные

Рабочая папка указана под списком архивов. У standalone-приложения она находится в пользовательском каталоге:

| Система | Каталог |
|---|---|
| Windows | `%LOCALAPPDATA%\LiveJournalArchive\archives` |
| macOS | `~/Library/Application Support/LiveJournalArchive/archives` |
| Linux | `$XDG_DATA_HOME/LiveJournalArchive/archives` или `~/.local/share/LiveJournalArchive/archives` |

В папке журнала: `index.html`, страницы записей, поиск, `help.html`, `data/activitystreams.json`, `data/archive.json`, рабочая база `archive.sqlite3`. История изменений хранится в базе и JSON. Параметры незавершённых задач находятся в общей папке `.jobs`; для переноса с продолжением загрузки скопируйте всю рабочую папку.

**Скачать ZIP** выдаёт страницы, медиа и оба JSON. **Скачать JSON** — [ActivityStreams 2.0 с расширениями ЖЖ](docs/activitystreams.md), включая полный исходный снимок. **Исходный JSON** — [прежний формат данных](docs/json-format.md). Рабочая база в ZIP не включается. Экспорт выполняется без сети; неизвестные поля, история изменений и сведения о пропусках сохраняются.

Сохраняется то, что ЖЖ возвращает владельцу, включая доступные личные записи и скрытые комментарии. Удалённые тексты и данные, которые сервис не возвращает, восстановить нельзя. Пропуски видны в состоянии архива; неизвестное число реакций не превращается в ноль. Доступ к файлам даёт доступ и к закрытым текстам внутри них.

## Из исходников

Python 3.10+:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -e .
python -m ljarchive serve
```

При запуске из исходников каталог по умолчанию — `./archives`. Другой можно задать через `serve --output ПАПКА`. Также есть `start.bat`, `start.command`, `start.sh`.

CLI запрашивает пароль отдельно:

```bash
python -m ljarchive export username --account --messages # журнал и личные данные
python -m ljarchive export username --limit 10         # тест, до 50 запросов
python -m ljarchive sync username --mode period --from 2005-01-01 --to 2005-12-31
python -m ljarchive sync username --mode urls --url https://username.livejournal.com/12345.html
python -m ljarchive sync username --mode full           # проверка и полное обновление
python -m ljarchive json archives/username --format activitystreams --output journal.json
python -m ljarchive json archives/username --format source --output source.json
python -m ljarchive build archives/username            # пересобрать HTML без сети
python -m ljarchive verify archives/username           # проверить локальные данные без сети
```

`--account` включает профиль, связи, настройки и каталог юзерпиков; `--messages` — переписку. `--images` включает изображения, `--delay 3` задаёт паузу, `--max-requests N` — необязательный лимит на один запуск. Для обновления тестового архива добавьте `--archive username-latest-10`. Код выхода выгрузки: 0 — выбранная задача завершена; 2 — частичная/остановленная; 1 — ошибка запуска или входа.

## Разработка и сборка

```bash
python -m pip install -e '.[test,browser,package]'
python -m pytest -q
python -m playwright install chromium
python tests/browser_smoke.py
python -m build
python packaging/build.py
python packaging/smoke.py
```

Тесты изолированы: ответы ЖЖ моделируются, браузер использует временную папку. Проверяются сохранение прогресса, лимиты, повторы, комментарии, реакции и авторы, целостность, обновления, экспорт, автономный поиск и мобильный интерфейс. Нативное приложение дополнительно запускается без Python-окружения на каждой целевой ОС. Полная выгрузка реального многолетнего журнала не входит в автоматические проверки.
