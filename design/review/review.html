Макет и сценарии

Предлагаемый интерфейс версии 0.3. Верхняя серая полоса — только навигация по макету. Данные вымышлены, подключения к ЖЖ нет.

Экраны

АрхивыСписок, состояние, открытие и меню действий. Без вводного блока и демонстрационных архивов.
СозданиеИмя, пароль, объём, изображения. Настройки загрузки раскрываются по необходимости.
Список записейПоиск, год, метка, доступ, порядок. Превью текста и счётчики.
ЗаписьТекст, компактные абзацы, реакции с авторами, дерево комментариев. Без справочных блоков вокруг текста.
СостояниеПроверяемые числа и конкретные пропуски. Детали свернуты.
ПомощьОдна страница, доступная из приложения и автономного архива.

Сценарии

  1. Первый запуск → «Новый архив» → весь журнал (по умолчанию) / за период / тест из последних 10 записей → «Создать» → ход загрузки → «Открыть».
  2. Обновление → пароль → период / ссылки / весь журнал → «Обновить». По умолчанию — последние 30 дней.
  3. Лимит, заданный в настройках → «Продолжить» → пароль → прежняя задача, сохранённое место, новый лимит запуска.
  4. Временный отказ ЖЖ → время следующей попытки → автоматическое продолжение. Если общий лимит задан, он не сбрасывается.
  5. Остановка → «Остановить» → сохранение прогресса → «Продолжить» сейчас или после перезапуска.
  6. Ошибка входа → короткое сообщение → «Повторить» → ввод пароля.
  7. Полное обновление → «Обновить» → «Весь журнал» → пароль → автоматическая проверка целостности и обновление → состояние архива.
  8. Чтение → поиск по тексту и комментариям → переход к записи или комментарию → авторы реакции по нажатию на счётчик.
  9. Экспорт → меню архива → JSON или ZIP. Для переноса с возможностью обновления — вся рабочая папка с базой.

Текст и оформление

Системный шрифт в управлении, спокойный шрифт для текста записей. Белая и тёмная темы. Отступ между абзацами — 10 px; ветки комментариев — компактные, с ограничением вложенности на телефоне.

Заголовки записей набраны тем же шрифтом, что и их текст. Из ЖЖ взяты значок пользователя у имён, «Настроение» и «Музыка» под записью, день недели в дате, отметки годов в списке. Прочитанные заголовки меняют цвет.

Названия действий: «Создать», «Открыть», «Обновить», «Продолжить», «Остановить». Статусы сообщают о факте или следующем действии. Успешная загрузка не сопровождается рекламными фразами. Пропуски не скрываются за статусом «Готов».

После утверждения

  1. Реализовать эти экраны, необязательный общий лимит запросов и сохранение параметров для продолжения задачи после перезапуска.
  2. Подключить одностраничную помощь; включить её в автономный архив.
  3. Проверить обновление старого архива, поиск, реакции, остановки, повторные запуски, мобильный экран и тёмную тему.
  4. Собрать и проверить Windows x64, macOS Apple Silicon, macOS Intel и Linux x86_64.
  5. Опубликовать версию 0.3.0 в GitHub Releases: пакеты, SHA-256, краткая инструкция и фактические ограничения выпуска.

Макет готов к утверждению. Изменения рабочего интерфейса и публикация релиза выполняются после согласования.
