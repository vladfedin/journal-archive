# Макет 0.3 — на утверждение

Откройте `review/index.html` или `review/review.html` в браузере. Сервер и доступ к сети не нужны. Все данные в макете вымышлены; логин и пароль никуда не отправляются. Серая полоска сверху относится только к просмотру макета и не входит в рабочий интерфейс.

## Решения

- Главная — список архивов. Создание и обновление — диалог. На первом запуске пустой список и кнопка «Новый архив».
- Создание: «Весь журнал» (первый и выбран по умолчанию), «За период», «Тест (последние 10 записей)». Изображения выключены. Для обычной выгрузки общий лимит запросов не задан; его можно включить в настройках. В режиме теста по умолчанию 50 запросов. Пауза 3 секунды. Настройки сохраняются с задачей.
- Одна команда «Обновить»: последние 30 дней по умолчанию, произвольный период, ссылки или весь журнал. Выбор «Весь журнал» автоматически включает проверку целостности локальных данных и полный проход. Отдельной команды проверки с обновлением нет.
- Продолжение восстанавливает параметры и очередь задачи, в том числе после перезапуска. От пользователя нужен пароль. Если пользователь задал лимит, он применяется к каждому запуску отдельно; автоматическое ожидание/повтор внутри запуска его не обнуляет.
- Архив автономен: список, поиск, фильтры, записи, комментарии, раскрытие авторов реакций. В оформлении нет рекламных фраз и общих инструкций.
- Предупреждения появляются по факту проблемы. В обычном чтении — краткая отметка со ссылкой на состояние, детали — на отдельной странице.
- Справка — `help.html`, одна страница с якорями. Будет доступна из приложения и включена в автономный архив. Для JSON остаётся отдельная техническая спецификация.
- Рабочий путь хранения остаётся совместимым с существующими архивами. Макет показывает пример пути, а приложение подставит фактический.

## Что требует реализации после утверждения

Новая разметка/CSS и контроллер состояний; поддержка отсутствующего общего лимита запросов в API, CLI и загрузчике без неявного порога в 50; короткие сообщения сервера; доступ к сохранённым параметрам задачи через API для кнопки «Продолжить»; одностраничная помощь; пересборка старых HTML с сохранением данных; обновлённые проверки UI и пакетов. Числа и содержимое в макете — пример, а не выгрузка.

Не входят в утверждаемый интерфейс: рекламные блоки, демонстрационный архив по умолчанию, пояснения к каждому полю, длинные сообщения об успешном сохранении. CLI demo остаётся инструментом тестирования.

## Выпуск после реализации

Планируемый выпуск: `v0.3.0`. Публикация в GitHub Releases после успешных тестов и проверки готовых пакетов на Windows x64, macOS Apple Silicon, macOS Intel, Linux x86_64. Файлы должны скачиваться непосредственно из Releases, без входа в GitHub. В комплекте — SHA-256 и краткая инструкция. Указание статуса подписи приложений и ограничений — в описании выпуска.

Принятая правка пользователя: весь журнал первым и по умолчанию; период вторым; тест последних 10 записей третьим. Фиксированный лимит первой пробы не переносится на обычную выгрузку. Пользователь согласовал одну команду «Обновить» с автоматической проверкой целостности в режиме «Весь журнал».

Текущее состояние: макет подготовлен; утверждение пользователя ещё не получено. Рабочие шаблоны и релиз не изменены.
